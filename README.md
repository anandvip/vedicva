# vedicva
Vedic VA - personal repository

## Jyotish Timing Report

`index.html` is a single, self-contained page (HTML, CSS and JavaScript inline, VA logo embedded) that maps favourable windows and calm phases from December 2026 to December 2030 for money, new ventures, learning, spiritual practice and pilgrimage, leisure travel, travel abroad, and vehicles and property.

- Method: Swiss Ephemeris, Lahiri ayanamsa, whole-sign houses, mean lunar node, Vimshottari dasha with 365.25-day years, Gochara from the Moon with vedha and Ashtakavarga. Every figure was computed twice by independent paths; the page gives dates only.
- The page shows derived placements (signs, houses, nakshatras, dasha dates) only. No birth date, time or place is stored in this repository.
- Traditional guidance, not financial advice.

Publish with GitHub Pages: Settings, Pages, deploy from branch `vipul`, folder `/ (root)`.
